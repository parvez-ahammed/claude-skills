ⓘ Acme Tasks - Feature guide

Recurring tasks

Make a task repeat on a schedule. When you complete a recurring task, Acme Tasks makes the next copy of the task for the next due date. A Project Owner can set a repeat on any task in the project. A Member can set a repeat only on tasks assigned to them.

Open from Task details Field Repeat For Project Owner and Member Shown in List and Calendar
ⓘ

In one line: the next copy of a recurring task is made when you mark the current copy Done. It is not made on a timer. The new copy gets the next due date from the repeat rule, the same title, assignee, labels and checklist, and an empty comment list.

Where the next task comes from

When is the next copy made?

The next copy is made at these times:

  • When you mark the task Done in the task list, on the board, or in the task details.
  • When a rule in Automations marks the task Done, for example "close the task when the linked pull request is merged".

The next copy is not made at these times:

  • When the due date passes. An overdue recurring task stays open. No new copy is made until you complete it.
  • When you delete the task. The repeat stops.
  • When you move the task back from Done to Open. The copy that was already made stays.
⚠

Archived projects

You cannot complete a task in an archived project. So no new copies are made in an archived project.

⚑

"Ends after"

If you set Ends after to a number of times, the repeat stops after that number of copies. The last copy shows "Last in series" next to the due date.

The feature, in short

What this does, requires, and does not do

What it does

  • Makes one new copy each time you complete the task.
  • Sets the next due date from the repeat rule.
  • Copies the title, assignee, labels and checklist.
  • Shows a repeat icon in the list and the calendar.

What it requires

  • The role Project Owner, or Member for your own tasks.
  • A due date on the task.

What it does not do

  • Make copies in advance. Only the next copy exists.
  • Copy comments or attachments.
  • Make a copy when the due date passes.

Vocabulary

The terms used here

Repeat rule
How often the task repeats: Daily, Weekly, Monthly, or Custom.
Series
All copies of one recurring task.
Ends after
The number of copies after which the repeat stops. Empty means the repeat does not stop.
Last in series
The text on the last copy before the repeat stops.

Getting there in the UI

How to make a task repeat

  1. Open the task

    Select the task in the list to open Task details.

  2. Set a due date

    The Repeat field is disabled until the task has a due date.

  3. Select a repeat rule

    In Repeat, select Daily, Weekly, Monthly or Custom.... Optional: set Ends after.

Who can use it

What each role can do

  • ✓Project Owner can set, change and stop the repeat on any task in the project.
  • ✓Member can set, change and stop the repeat only on tasks assigned to them.
  • ✓Viewer sees the repeat icon, but the Repeat field is read-only.

On the screen

Messages you may see

"Next task created for 12 May."
You completed a recurring task. The new copy is in the list.
"Set a due date to repeat this task."
The task has no due date. Set one, then select a repeat rule.
"Could not create the next task. Try again."
The task is Done, but the new copy was not made. Move the task back to Open and complete it again.

Good to know

Known behaviours and things to watch

⚠

Late completion does not skip dates

The next due date is counted from the old due date, not from today. If you complete a daily task three days late, the new copy is also overdue.

⚑

Month ends

A monthly task due on the 31st is due on the last day of shorter months.
