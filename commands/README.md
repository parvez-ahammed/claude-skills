# Commands

User-fired prompt shortcuts (`/name`) for Claude Code. A command is a markdown file
whose body is the prompt; install by copying into `~/.claude/commands/` (personal) or a
project's `.claude/commands/`.

None yet - this directory is a placeholder. Add commands here as repeatable,
user-initiated prompts emerge (e.g. a project bring-up, a release checklist). For
model-judgment workflows prefer a **skill**; for automatic enforcement prefer a **hook**.
